完整服務流程
天使商務生態圈 SOP
← 回後台
從客戶第一次掃到名片，到智慧名片正式上線的完整路徑。
每位客戶都走這條流程，每個步驟完成才進入下一步。
①
客戶入口
客戶掃到名片或收到連結
點「品牌診斷／免費諮詢」CTA，進入診斷系統首頁。
②
客戶自助完成
客戶填 5 步診斷問卷
送出後立即取得：
  • 專屬查詢代碼（例：8888A3）
  • 即時品牌卡點分析
  • 影音經營建議方向
客戶會把代碼透過 LINE OA 傳給 Angel
③
Angel 操作｜後台 Mode A
查代碼 → 產診斷報告 → 傳給客戶
  • 後台 Mode A 輸入代碼查詢
  • 複製「綜合診斷指令」→ 貼給 Claude
  • 報告存成 HTML（{姓名}-{代碼}.html）→ 上傳 reports/
  • 後台按「傳診斷報告連結」→ 傳 LINE 給客戶
④
客戶自助完成
客戶填品牌素材表（深化合作時）
Angel 在後台點「素材收集邀請」傳連結給客戶，或客戶在診斷結果頁自行點進去。約 5 分鐘填完，含照片上傳。
完成後客戶會拿到素材代碼
⑤
Angel 操作｜後台 Mode B
查素材代碼 → 選方案 → 產 7 個分頁指令
  • 後台 Mode B 輸入素材代碼
  • 選合作方案（名片建卡／基礎／中階／全包）
  • 逐一複製 7 個分頁指令貼給 Claude
  • ⭐ Tab 0 的 Claude 回應結尾有 JSON，複製備用
  • 品牌方案報告存成 HTML → 上傳 reports/
  • 後台按「傳品牌方案連結」→ 傳 LINE 給客戶
⑥
Angel 操作
傳自我評量連結給客戶
後台 Mode B 按 「📊 傳自我評量連結」，客戶填寫：優先順序排序、內容健康比例自評、了解服務界線。
⑦
Angel 操作｜名片內容管理後台
貼 JSON → 建立案件 → 傳勾選連結
  • 打開 card-admin.html
  • 貼上步驟⑤的 JSON → 建立案件
  • 取得客戶專屬勾選連結 → 傳給客戶
⑧
客戶自助完成
客戶勾選名片內容版本
客戶在 card-select.html 選擇喜歡的品牌故事、理念金句、跑馬燈版本。送出後 Angel 回 card-admin.html 複製最終內容。
⑨
Angel 操作｜HSC 後台
填入名片內容，名片正式上線
把最終內容手動填入 HSC 智慧名片後台，完成建卡或更新。
✦
收尾確認
8 項完成才算服務結束
見下方清單
✅ 名片完成收尾檢查清單（每位客戶必做）
名片欄位與客戶勾選結果逐項核對一致
實際打開名片連結測試，CTA 按鈕、聯繫方式都能正常運作
確認客戶已完成付款
名片正式啟用
最終名片連結傳給客戶
品牌顧問後台「04_品牌DNA輸出」狀態改為「已完成」
card-admin.html 案件狀態改為「已確認」
天使商務 CRM（若有需求記錄）狀態改為「已成交」

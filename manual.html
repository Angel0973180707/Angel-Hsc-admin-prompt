🔍 Mode A｜綜合診斷
客戶填完診斷問卷後，Angel 在這裡查詢並產出診斷報告
步驟 1
查詢診斷代碼
客戶完成品牌診斷後，會收到一組 6 碼的查詢代碼（例：8888A3）。
在後台 Mode A 輸入框貼上代碼，按「查詢」。
客戶會把代碼用 LINE 傳給你，或你在 LINE OA 的對話裡找到。
步驟 2
複製「綜合診斷指令」→ 貼給 Claude
查詢成功後，點 📋 複製診斷指令 按鈕，把整段指令貼到 Claude 對話框，等待 Claude 輸出完整診斷報告。
輸出內容很長，Claude 可能需要 1-2 分鐘。報告包含：品牌卡點分析、定位建議、名片解決方案、行動清單。
步驟 3
存成 HTML，上傳 reports/
Claude 輸出的報告，在 Claude 右上角點「複製 HTML」，存成檔案。

檔名格式：{客戶姓名}-{查詢代碼}.html
例：陳老闆-8888A3.html

上傳到 HSC 後台的 reports/ 資料夾。
上傳後，HSC 後台「更多 → 提案專區」就能看到這份報告，可一鍵複製連結。
步驟 4
傳診斷報告連結給客戶
回到品牌顧問後台，點 📤 傳診斷報告連結 按鈕，複製文案後傳到 LINE。
🚀 Mode B｜品牌方案
客戶填完素材收集表後，Angel 在這裡產出完整品牌方案（7 個分頁指令）
步驟 1
查詢素材代碼 + 選方案
客戶填完素材表後會拿到素材代碼，輸入後按查詢。
查到資料後，選擇合作方案：

名片建卡：只做名片
基礎：名片 + 第一支影音
中階：名片 + 每月腳本代寫
全包：名片 + 全部內容產出
步驟 2
逐一複製 7 個分頁指令貼給 Claude
查詢成功後出現 7 個分頁，每個分頁都有一段指令，依序複製貼給 Claude：

Tab 0 名片內容（⭐ 最重要，回應裡會有 JSON）
Tab 1 一頁式網頁
Tab 2 影音腳本
Tab 3 社群文案
Tab 4 商業閉環
Tab 5 交付清單
Tab 6 LINE 摘要
⭐ Tab 0 Claude 回應結尾會有一段 JSON，複製保存，之後要貼到名片內容管理後台。
步驟 3
存成 HTML，上傳 reports/
同 Mode A，把品牌方案報告存成 HTML 上傳到 reports/。
檔名：{客戶姓名}-{素材代碼}.html
步驟 4
傳品牌方案連結 + 自我評量連結
點 📤 傳品牌方案連結 傳給客戶。

接著點 📊 傳自我評量連結，讓客戶填寫經營優先順序評量。
📋 Mode C｜手動貼入
當 Mode A / B 查不到資料時的備用方式
使用時機
代碼查不到資料，或想直接從 Google Sheets 複製客戶資料來用。

做法：打開診斷系統 Sheets → 找到該客戶那列資料 → 把欄位內容複製貼到 Mode C 的對應欄位。
只有真的查不到才用這個模式，一般情況用 Mode A / B 即可。
❓ 常見狀況
查詢後沒有資料？
1. 確認代碼輸入正確（英數大小寫）
2. 客戶填表後到 GAS 寫入需要幾秒，等一下再查
3. 試試 Mode C 手動貼入
按鈕複製後貼到 Claude 沒反應？
確認剪貼簿有內容，重新複製再貼一次。
如果 Claude 說看不懂，通常是貼到錯的地方，確認貼到 Claude 的對話輸入框。
報告存成 HTML 怎麼操作？
在 Claude 回應右上角有「複製」→ 新增一個空白的 .html 檔 → 全部貼入 → 存檔 → 用瀏覽器開啟確認格式正常 → 上傳到 HSC 後台 reports/ 資料夾。
